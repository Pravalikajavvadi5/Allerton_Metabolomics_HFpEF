# Allerton_Metabolomics_HFpEF

This repository contains metabolomics data from ZSF1 rats, profiling disease progression and treatment response.

## Data Files

**OG_Metabolon_data** : Original metabolomics data provided by Metabolon, containing peak area data, sample metadata, chemical annotation, batch-imputed data, and batch-normalized data

**ZSF1_Rat_metabolomics_sample_level_norm_data** : Metabolomics data normalized at the sample level using MetaboAnalyst
